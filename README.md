GPS-Based Bus Tracking and Passenger Information System
This project is an Arduino-based GPS bus tracking and passenger notification system developed for academic purposes.

The system uses push buttons and GSM/GPRS communication to send requests to a remote server and display the received response on an LCD screen.

## Features

* Push button request system
* GSM/GPRS communication
* LCD information display
* Remote server response handling
* Arduino Mega based system
* Proteus simulation support

## Technologies Used

* Arduino Mega
* SIM900 Shielded GPRS Module
* 20x4 I2C LCD
* Push Buttons
* Arduino IDE
* Proteus Simulation
